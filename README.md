# Telco Customer Churn Prediction

CM2604 Machine Learning coursework (Part 01). Predicts whether a telecom customer will churn using KNN, Logistic Regression and Random Forest.

## Dataset
Telco Customer Churn (Kaggle, IBM sample data), 7,043 customers, 21 columns. File: `data/WA_Fn-UseC_-Telco-Customer-Churn.csv`

## Contents
- `Task1_eda.ipynb`: exploratory data analysis
- `Task2_preprocessing_models.ipynb`: preprocessing, modelling, tuning, evaluation, fairness check
- `results/`: comparison and fairness tables
- `requirements.txt`: Python dependencies

## How to run
1. `python -m venv .venv` and activate it
2. `pip install -r requirements.txt`
3. Open the notebooks in VS Code or Jupyter and Run All
